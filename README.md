# Laptop Troubleshooting Expert System

A rule-based AI expert system developed as a micro project for the **Foundation of Artificial Intelligence (2ADPC204)** course at Annasaheb Dange College of Engineering and Technology (ADCET).

## 📌 Project Overview
This project is an interactive, rule-based diagnostic application built in Python. It asks users simple yes/no questions about laptop issues, applies **Forward Chaining** to identify potential causes, verifies the findings using **Backward Chaining**, and suggests practical solutions.

---

## 🚀 Features
- **Interactive Diagnosis:** Simple CLI-based question/answer interface.
- **5 Common Categories Covered:**
  1. Laptop not starting
  2. Laptop not charging
  3. Laptop overheating
  4. Laptop running slowly
  5. Wi-Fi not working
- **Dual Inference Engine:**
  - **Forward Chaining:** Data-driven search to infer possible causes from user facts.
  - **Backward Chaining:** Goal-driven verification to confirm the rules support the inferred diagnosis.
- **Actionable Solutions:** Provides tailored troubleshooting steps for every verified condition.
